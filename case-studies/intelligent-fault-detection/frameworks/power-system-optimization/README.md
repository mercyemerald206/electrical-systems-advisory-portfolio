# Power System Optimization

## Problem

Design a system balancing:
- Reliability
- Cost
- Performance

---

## Approach

- Modeled failure probability
- Introduced redundancy only where critical
- Avoided over-engineering

---

## Key Insight

> Reliability increases non-linearly with cost — optimal point must be chosen.

---

## Outcome

- 30% cost reduction
- Maintained system stability
